`antex` is a small library to parse and process ANTEX (Antenna RINEX files) databases so they
can serve your applications.

To contribute to either of our project or join our community, you way
- open an [Issue on Github.com](https://github.com/nav-solutions/antex/issues) 
- follow our [Discussions on Github.com](https://github.com/nav-solutions/discussions)
- join our [Discord channel](https://discord.gg/EqhEBXBmJh)

## Advantages

- Fast
- Open sources: read and access all the code

## Other RINEX formats

- our [RINEX parser](https://github.com/nav-solutions/rinex) provides support for
RINEX standard formats (Observation, Meteo, Navigation, Clock)

- our [IONEX parser](https://github.com/nav-solutions/ionex) provides support for
the IONEX (Ionosphere Maps) format
